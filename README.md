# SisterGolf website (static copy)

This repo holds a static copy of the SisterGolf WordPress site that ran at sistergolfonline.com.
Netlify and GitHub Pages serve these files as they are. There is no build step.

- To refresh the copy from WordPress (while WordPress is still online): open the Actions tab, select "Mirror WordPress site", click "Run workflow".
- The previous redesign (React/Lovable) is in this repo's history at commit 09db850.
- Forms that need WordPress (contact form, site search) do not work in a static copy. Links to outside services (membership, PayPal, Amazon, Mailchimp) still work.
